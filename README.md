# WOL Pro - Wake-on-LAN Приложение

Кроссплатформенное приложение для удалённого запуска устройств в сети через протокол Wake-on-LAN (WOL) с современным веб-интерфейсом на Go + Wails.

## Возможности

- 🌐 **Управление устройствами** - добавление, редактирование и удаление устройств
- 🚀 **Быстрое включение** - отправка волшебных пакетов одним кликом
- 💾 **Автосохранение** - список устройств автоматически сохраняется в JSON
- 🎨 **Современный интерфейс** - темная тема, интуитивный пользовательский интерфейс
- 🔧 **Кроссплатформенность** - работает на Windows, macOS и Linux
- 🌍 **Русский язык** - полная локализация на русском языке
- ⚡ **Высокая производительность** - быстрая загрузка благодаря Go
- 🔄 **Горячая перезагрузка** - поддержка разработки с `wails dev`

## Требования

- **Go 1.21+** - для сборки из исходного кода
- **Wails 2.6+** - для сборки и разработки
- Для готового приложения: Windows 10+, macOS 11+, Linux с GTK3+

## Быстрый старт

### Использование готового приложения

Скачайте бинарный файл для вашей платформы с [GitHub Releases](https://github.com/bikuta13/WOL-Pro/releases) или из папки [release-builds](release-builds/).

Доступные готовые сборки:
- `WOL-Pro-macOS-arm64.zip` - macOS Apple Silicon (M1/M2/M3/M4)
- `WOL-Pro-macOS-amd64.zip` - macOS Intel
- `WOL-Pro-Windows-amd64.zip` - Windows 64-bit

### Из исходного кода

```bash
# 1. Клонирование
git clone https://github.com/bikuta13/WOL-Pro.git
cd wol-pro

# 2. Установка Go (если еще не установлен)
# Скачайте с https://golang.org/dl

# 3. Установка Wails
go install github.com/wailsapp/wails/v2/cmd/wails@latest

# 4. Запуск в режиме разработки (с горячей перезагрузкой)
wails dev

# Или просто скомпилируйте
go build -o wol-pro
```

## Сборка приложения

### macOS (M4 / Apple Silicon)

```bash
wails build -platform darwin/arm64 -o "WOL Pro"
# Результат: ./build/bin/WOL Pro.app
```

### macOS (Intel x86_64)

```bash
wails build -platform darwin/amd64 -o "WOL Pro"
# Результат: ./build/bin/WOL Pro.app
```

### Windows (AMD64)

```bash
wails build -platform windows/amd64 -o "WOL-Pro.exe"
# Результат: ./build/bin/WOL-Pro.exe
```

### Linux (x86_64)

```bash
wails build -platform linux/amd64 -o wol-pro
# Результат: ./build/bin/wol-pro
```

### Использование скрипта сборки

```bash
chmod +x build.sh
./build.sh
```

## Использование приложения

### Добавление устройства

1. Нажмите кнопку **"➕ Добавить"**
2. Заполните форму:
   - **Название устройства**: имя устройства (например, "Рабочий компьютер")
   - **MAC адрес**: физический адрес устройства (формат: `XX:XX:XX:XX:XX:XX`)
   - **IP адрес**: (опционально) IP адрес для целевой отправки пакета
3. Нажмите **"Сохранить"**

### Включение устройства

1. Выберите устройство из списка
2. Нажмите кнопку **"▶️ Включить (Wake)"**
3. Волшебный пакет будет отправлен на устройство

### Редактирование устройства

1. Выберите устройство из списка
2. Нажмите кнопку **"✏️ Редактировать"**
3. Внесите изменения и нажмите **"Сохранить"**

### Удаление устройства

1. Выберите устройство из списка
2. Нажмите кнопку **"🗑️ Удалить"**
3. Подтвердите удаление

## Поиск MAC адреса устройства

### Windows

```cmd
ipconfig /all
```

Ищите "физический адрес" (Physical Address)

### macOS

```bash
ifconfig
```

Ищите "ether" в выводе вашего сетевого интерфейса

### Linux

```bash
ip link show
```

или

```bash
ifconfig
```

## Хранение данных

Список устройств сохраняется в JSON файле:

```
~/.config/wol-pro/devices.json
```

## Предварительные условия для WOL

Для работы WOL необходимо:

1. **Целевое устройство должно поддерживать WOL**
2. **Функция WOL должна быть включена в BIOS/UEFI** целевого устройства
3. **Сетевая карта должна быть подключена к питанию** в режиме ожидания
4. **Устройство должно быть в сети** (в подсети источника или настроена трансляция)
