# CHANGELOG

Все заметные изменения в этом проекте будут задокументированы в этом файле.

## [2.0.1] - 2026-06-12

### Улучшено
- Добавлена валидация IPv4 адреса при добавлении и редактировании устройств.
- Добавлена стабильная сортировка устройств по имени.
- Ответы API Wails переведены на структурированный `Result` с boolean `success`.
- Сканер MAC предварительно обновляет ARP-таблицу через `ping`.
- Обновлены готовые сборки для macOS Apple Silicon, macOS Intel и Windows x64.

## [2.0.0] - 2026-04-07

### 🎉 Полный переход на Go + Wails

#### Добавлено
- ✨ **Go 1.21 бэкенд**: переписан на языке Go для лучшей производительности
- 🎨 **Wails 2 GUI**: современный веб-интерфейс на HTML/CSS/JavaScript
- 🚀 **Улучшенная архитектура**: четкое разделение на бэкенд и фронтенд
- 📦 **Более компактный размер**: значительно меньше места на диске
- ⚡ **Лучшая производительность**: быстрая загрузка и отклик
- 🌙 **Темная тема**: современный темный интерфейс по умолчанию
- 🔄 **Горячая перезагрузка**: поддержка `wails dev` для разработки

#### Измененное
- 🔄 Переписана система управления устройствами (Go вместо Python)
- 🔄 Переписана отправка WOL пакетов
- 🔄 Обновлены скрипты сборки для Go + Wails
- 🔄 Полностью переработан интерфейс (HTML/CSS/JS вместо tkinter)

#### Удалено
- ❌ Python зависимости (tkinter, PyInstaller и т.д.)
- ❌ Файлы Python кода (все переписано на Go)
- ❌ requirements.txt (используется go.mod вместо этого)

### Функциональность
- ✅ Управление списком устройств (добавление, редактирование, удаление)
- ✅ Отправка WOL пакетов выбранному устройству
- ✅ Валидация MAC адресов
- ✅ Поддержка опционального IP адреса для целевой отправки
- ✅ Логирование операций
- ✅ Сохранение конфигурации в JSON

### Платформы
- Windows 10/11+ (AMD64)
- macOS 11+ (Apple Silicon / M4 и Intel x86_64)
- Linux (x86_64, требует GTK3+)

### Технология
- Go 1.21+
- Wails v2.6+
- HTML5 + CSS3 + Vanilla JavaScript
- Встроенный WebKit браузер

## [1.0.0] - 2026-04-07 (Устаревшего - Python версия)

### Добавлено
- ✨ **Основной функционал WOL**: отправка волшебных пакетов для включения устройств в сети
- 🎨 **Графический интерфейс**: полноценный GUI на основе tkinter с поддержкой русского языка
- 💾 **Управление устройствами**: добавление, редактирование и удаление устройств
- 📝 **JSON хранилище**: автоматическое сохранение списка устройств
- 🌍 **Кроссплатформенность**: поддержка Windows AMD64, macOS M4 и Linux
- 🔨 **Автоматическая сборка**: скрипты для компиляции приложения под разные платформы
- 📖 **Документация**: подробные инструкции по использованию и сборке

### Платформы
- Windows 10/11+ (AMD64)
- macOS 11+ (M4 / Apple Silicon)
- Linux (с поддержкой tkinter)

### Технология
- Python 3.11+
- tkinter (встроенный GUI фреймворк)
- PyInstaller для сборки
